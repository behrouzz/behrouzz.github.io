VizieR

Another really useful service created by CDS, is the VizieR Catalogue Service. If you already know which catalog you want to use, this is the best place to retrieve data from that catalog.

Find catalogue and retrieve data with astroquery

If you don't know which catalog to use, you can easily search the VizieR website to find which catalog is best for your job. If you prefer search for catalogs programatically, you can use .find_catalogs() method of the Vizier class. You pass the keyword(s) you are searching for to the method. The method wil return an OrderedDict object.

>>> from astroquery.vizier import Vizier
>>> viz = Vizier.find_catalogs('SDSS')
>>> for k, v in viz.items():
	print(k, ':', v.description)

V/154 : Sloan Digital Sky Surveys (SDSS), Release 16 (DR16) (Ahumada+, 2020)
VII/289 : SDSS quasar catalog, sixteenth data release (DR16Q) (Lyke+, 2020)

At the left side of the above results, you can see the catalogue names, and at the right side you see a description for each catalogue. You should use these names to retrieve data from a catalogue.

You can search objects by identifier or by coordinates the same way we did for SIMBAD. Let's search for the star Vy Canis Major: 


>>> res = Vizier.query_object("Vy Canis Major")
>>> type(res)

>>> len(res)
296

The return result is a TableList object and in this case it contains 296 tables.

When you already know the name of the catalogue and you want to search an object in it, you can specify the catalog argument of the query_object function. You can also use this argument when searching in a region with the query_region function. In the following example we search in a very narrow region of the sky in the SDSS DR16 catalogue. As we saw above, the table name of this catalogue in Vizier is V/154. Since we are searching in a single catalogue, the result has only one table.

from astroquery.vizier import Vizier
import astropy.units as u
from astropy.coordinates import SkyCoord

c = SkyCoord(ra=179.68929, dec=-0.45438, unit='deg')
res = Vizier.query_region(c, radius=5*u.arcsec, catalog='V/154')
print('Number of tables:', len(res))
print(res[0])

Not all columns in the catalogue will be returned. If you want to specify exactly which columns should be returned, you should do the query in another way. You should create an instance of the Vizier class and specify the columns names. In this way, you have also the ability to filter columns based on certain condition. As an example, we want to search a sky region the SDSS DR16 catalogue, but we need the objects that have redshifts. We want just certain columns to be returned: the identifier, magnitudes in g, r and i bands and the redshift. Note that we have applied the filter via the column_filters argument.

from astroquery.vizier import Vizier
import astropy.units as u
from astropy.coordinates import SkyCoord

viz = Vizier(columns=['objID', 'gmag', 'rmag', 'imag', 'zsp'],
             column_filters={"zsp":"NOT NULL"})

c = SkyCoord(ra=179.68929, dec=-0.45438, unit='deg')

tables = viz.query_region(c, radius=5*u.arcmin, catalog='V/154')

print(tables[0])

Tap Queries

For more advanced queries it is recommended to use tap queries. The astroquery.visier has not provided yet a tap query function. We can use our own function sql2df. Let's do the search region that we did earlier with astroquery:

from astrobook import sql2df

ra = 179.68929
dec = -0.45438
r = 0.083 # radius in degrees

query = f"""
SELECT objID, gmag, rmag, imag, zsp
FROM "V/154/sdss16"
WHERE zsp IS NOT NULL
AND
CONTAINS(POINT('ICRS', ra_icrs, de_icrs), CIRCLE('ICRS', {ra}, {dec}, {r})) = 1
"""

df = sql2df(query, api='vizier')
print(df)

Output:

                 objID    gmag    rmag    imag      zsp
0  1237648720693756163  17.762  16.589  16.080  0.12509
1  1237648720693690639  20.015  18.681  18.118  0.00018
2  1237648720693690602  18.415  17.565  17.184  0.08381
3  1237648720693690487  16.880  16.582  16.479  0.00060
4  1237648720693755918  17.603  16.827  16.438  0.09484
5  1237674649928532213  18.493  17.737  17.419  0.00019

Note that here we entered the radius in degrees. We also used the complete name of the table "V/154/sdss16" in quotation marks.

To retrieve table names and description of VisieR with tap query, you can simply use the following code:

>>> df = sql2df('SELECT table_name, description FROM TAP_SCHEMA.tables', api='vizier')

To get columns of a specific table:

>>> query = """
SELECT column_name, description
FROM TAP_SCHEMA.columns
WHERE table_name='V/154/sdss16'
"""
>>> df = sql2df(query, api='vizier')

There are also other things VizieR can do, such as search for spectra and images. You can use this feature on the VizieR website.
