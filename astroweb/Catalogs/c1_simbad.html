SIMBAD

SIMBAD is an online database, maintained by Centre de données astronomiques de Strasbourg (CDS). As of Jully 2024, it contains information fore more than 18 million deep sky objects. It is especially usefull when you want to do cross catalogue searches. You can access the database in different ways.

Query by identifier

If you need information for a certain object, you can type its name or identifier on the SIMBAD website. If you prefere a pythonic way, you can use astroquert package:

>>> from astroquery.simbad import Simbad
>>> table = Simbad.query_object("m31")
>>> print(table.to_pandas().iloc[0])

RA                         00 42 44.330
DEC                        +41 16 07.50
RA_PREC                               7
DEC_PREC                              7
COO_ERR_MAJA                        NaN
COO_ERR_MINA                        NaN
COO_ERR_ANGLE                         0
COO_QUAL                              C
COO_WAVELENGTH                        I
COO_BIBCODE         2006AJ....131.1163S
SCRIPT_NUMBER_ID                      1
Name: 0, dtype: object

You can see that the resulting table contains a few columns that give some information about the coordinates. You may need many more information, such as parallax. In this case, you can first create an instance of the Simbad class, then use .add_votable_fields() and pass it your desired columns names.

>>> from astroquery.simbad import Simbad
>>> simbad = Simbad()
>>> simbad.add_votable_fields('parallax')
>>> table = Simbad.query_object("m31")
>>> print(table.to_pandas().iloc[0])
MAIN_ID                           M  31
RA                         00 42 44.330
DEC                        +41 16 07.50
RA_PREC                               7
DEC_PREC                              7
COO_ERR_MAJA                        NaN
COO_ERR_MINA                        NaN
COO_ERR_ANGLE                         0
COO_QUAL                              C
COO_WAVELENGTH                        I
COO_BIBCODE         2006AJ....131.1163S
PLX_VALUE                           6.0
PLX_PREC                              1
PLX_ERROR                          14.1
PLX_QUAL                              E
PLX_BIBCODE         1995GCTP..C......0V
SCRIPT_NUMBER_ID                      1
Name: 0, dtype: object

Now, you the table contains the parallax information along with the default columns. To see which options you can add to get back the output columns use .list_votable_fields() method.

If you want to search for multiple objects, instead of query_object, you should use query_objects. Lets get some data of four stars of the Orion constellation:

>>> table = Simbad.query_objects(['Betelgeuse', 'Bellatrix', 'Rigel', 'Saiph'])
>>> print(table)

Query by coordinates

If you are looking for objects at a cetrain location in the sky, you can use the query_region function. You give your desired coordinates and the radius of the region your are searching.

>>> from astroquery.simbad import Simbad
>>> from astropy.coordinates import SkyCoord
>>> import astropy.units as u
>>> coord = SkyCoord(ra=10.68470833, dec=41.26875, unit='deg')
>>> table = Simbad.query_region(coordinates=coord, radius=10*u.arcsec)
>>> print(table[:5])
               MAIN_ID                     RA      ... SCRIPT_NUMBER_ID
                                        "h:m:s"    ...                 
------------------------------------- ------------ ... ----------------
                                M  31 00 42 44.330 ...                1
                        [HPH2013] 167  00 42 44.36 ...                1
                        [O2006] QSS 8 00 42 44.365 ...                1
[CHM2007] LDC   31 J004244.33+4116074   00 42 44.3 ...                1
                            NAME M31*  00 42 44.33 ...                1

There's an argument criteria that can be used to filter the results based on some criteria. This an argument that can be used for som other functions, such as query_object, too. This argument accepts ADQL statements as a string. You can refer to astoquery documentations if you like. But I don't recommend using these kinds of options for advanced searches.

>>> table = Simbad.query_region(
	coordinates=coord,
	radius=10*u.arcsec,
	criteria="otype = 'Galaxy..'"
	)
>>> print(table)
               main_id                        ra         ...     coo_bibcode    
                                             deg         ...                    
------------------------------------- ------------------ ... -------------------
[CHM2007] LDC   31 J004244.33+4116074  10.68458333333333 ... 2007ApJ...655..790C
                                M  31 10.684708333333333 ... 2006AJ....131.1163S

As with the query_object, you can use .add_votable_fields() to control the output columns. For simple tasks, they are pretty good and useful, but for a more complicated search, it is better to use Tap queries.

Tap queries

import pandas as pd
from requests import request
from io import StringIO

def sql2df(script, api):
    script = ' '.join(script.strip().split('\n'))
    url = api + script.replace(' ', '%20') + '&format=csv'
    res = request('GET', url).content.decode('utf-8')
    return pd.read_csv(StringIO(res))

SIMBAD_API = 'https://simbad.u-strasbg.fr/simbad/sim-tap/sync?request=doQuery&lang=adql&query='

df = sql2df('SELECT TOP 10 main_id, ra, dec FROM basic', SIMBAD_API)
print(df)
