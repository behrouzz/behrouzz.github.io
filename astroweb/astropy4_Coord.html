Astropy Coordinates

When we talk about coordinates in astronomy, we mean a point or an array of points in the sky. In most cases, not always, the coordinates of a point in the sky is expressed by two numbers. For example, most star catalogs store coordinates of stars by in the ICRS frame. To express the coordinate of an object in ICRS, you need two numbers, RA and DEC. If you use the Galactic frame, the two numbers should be expressed as L and B.

Basic SkyCoord object

In astropy, we use the SkyCoord class from the coordinates subpackage to represent a point or an array of poins in the sky. The arguments depend on the frame you choose. For example, if you choose the frame as 'icrs' you have to provide arguments ra and dec. Both ra and dec are angles, so their unit should be an angle unit, such as degrees, radians, etc. You can also pass them as numerical values, but in this case you have to indicate their unit by passing the chosen unit to the unit argument.

In the example below, we pass ra and dec as quantities:

>>> import astropy.units as u
>>> from astropy.coordinates import SkyCoord
>>> c = SkyCoord(ra=101.287*u.deg, dec=-16.716*u.deg, frame='icrs')
>>> c
<SkyCoord (ICRS): (ra, dec) in deg
    (101.287, -16.716)>

We can also pass ra and dec as numerical values and explicitly indicate unit in the unit argument:

>>> c = SkyCoord(ra=101.287, dec=-16.716, unit='degree', frame='icrs')
>>> c
<SkyCoord (ICRS): (ra, dec) in deg
    (101.287, -16.716)>

The coordinates arguments should be chosen wisely according to the frame. Let's create a SkyCoord object in the Galactic frame:

>>> c = SkyCoord(l=227.23012017*u.deg, b=-8.89036478*u.deg, frame='galactic')
>>> c
<SkyCoord (Galactic): (l, b) in deg
    (227.23012017, -8.89036478)>

The easiest way to transfrom the coordinates to aother frame is to use the name of the frame as attribute:

>>> c = SkyCoord(ra=101.287*u.deg, dec=-16.716*u.deg, frame='icrs')
>>> c.galactic
<SkyCoord (Galactic): (l, b) in deg
    (227.23012017, -8.89036478)>

The coordinates components

You can get each of the coordinates components from the SkyCoord object using attributes. The result will be a quantity corresponding to that component. In the example below, .ra attribute returns a Longitude object, while .dec attribute returns a Latitude object.

>>> c = SkyCoord(ra=101.287*u.deg, dec=-16.716*u.deg, frame='icrs')
>>> c.ra
<Longitude 101.287 deg>
>>> c.dec
<Latitude -16.716 deg>

If you want to get back the numerical value of a coordinate component in degrees or in radians, use .deg or .rad after the component attribute:

>>> c.ra.deg
101.287
>>> c.ra.rad
1.7677916394674966

You can alse get back the coordinates in some string formats using .to_string() method:

>>> c = SkyCoord(ra=101.287*u.deg, dec=-16.716*u.deg, frame='icrs')
>>> c.to_string('decimal')
'101.287 -16.716'
>>> c.to_string('dms')
'101d17m13.2s -16d42m57.6s'
>>> c.to_string('hmsdms')
'06h45m08.88s -16d42m57.6s'

Advanced SkyCoord object

As explanied above, you can create a SkyCoord object by passing just two coordinates components, such as ra and dec. Sometimes you may have more information about the body. Adding these optional informations, make the coordination object more powerfull. Some common optional arguments are:

  • distance: distance to the frame origin
  • radial_velocity: radial velocity with respect to the frame origin
  • pm_ra_cosdec and pm_dec: proper motion
  • obstime: time of observation
  • location: location of observation site on the Earth
  • temperature: temperature at observation site
  • pressure: pressure at observation site

We introduce only distance, obstime and location in this section. Other arguments will be covered in later chapters.

Adding distance

Perhaps you know the distance of the body from the frame origin. For example, we know that the distance of the star Sirius from the Solar System barycenter is about 8.6 light years. We can pass distance argument as follow::

>>> c = SkyCoord(
	ra=101.287155333 * u.deg,
	dec=-16.716115861 * u.deg,
	frame='icrs',
	distance=8.6 * u.lyr
	)
>>> print(c)
<SkyCoord (ICRS): (ra, dec, distance) in (deg, deg, lyr)
    (101.28715533, -16.71611586, 8.6)>

Now, we have a more powerful object. We can, for example, get not only galactic, but also galactocentric coordinates:

>>> c.galactocentric
<SkyCoord (Galactocentric: galcen_coord=, galcen_distance=8.122 kpc, galcen_v_sun=(12.9, 245.6, 7.78) km / s, z_sun=20.8 pc, roll=0.0 deg): (x, y, z) in lyr
    (-26496.10721763, -6.23731206, 66.52622131)>

Using .cartesian attribute, we can get a CartesianRepresentation object of the coodinates. This new object, have certain attributes such as .x, .y and .z:

>>> c.cartesian
<CartesianRepresentation (x, y, z) in lyr
    (-1.61211497, 8.07727075, -2.47361731)>
>>> c.cartesian.x
<Quantity -1.61211497 lyr>

Adding time of observation

When you create a basic SkyCoord object, you do not indicate the observation time. Sometimes it does not make sens at all. But what if we want to get the geocentric position of a body? We can use .gcrs attribute to convert the coordinates from ICRS to GCRS. Let's see what happens in a simple case:

>>> c = SkyCoord(ra=101.2872 * u.deg, dec=-16.7161 * u.deg)
>>> c.gcrs
<SkyCoord (GCRS: obstime=J2000.000, obsgeoloc=(0., 0., 0.) m, obsgeovel=(0., 0., 0.) m / s): (ra, dec) in deg
    (101.2932251, -16.71644932)>

The origin of ICRS is the barycenter of the Solar System, while the origin of GCRS is the barycenter of the Earth. So, when you want to convert ICRS coordinates to GCRS coordinates, you need to know the position of the Earth. Astropy uses an internal routine to find the position of the Earth. But the position of the Earth at which moment in the time? Note the phrase obstime=J2000.000 in the above results. This is the time that astropy has chosen by default to calculate the position of the Earth in order to convert ICRS to GCRS. In other words, in the above example we got the geocentric coordinates of the body at the time J2000.000, i.e., the mid-day of January 1st 2000.

But what if we want to find the geocentric coordinates of the body at our desired time? In this case, we can simply provide the obstime argument when creating the SkyCoord object. Note that we have to enter the time as an astropy Time object.

>>> from astropy.time import Time
>>> t = Time('2024-07-13 22:35:40', scale='utc')
>>> c = SkyCoord(ra=101.2872*u.deg, dec=-16.7161*u.deg, obstime=t)
>>> c.gcrs
<SkyCoord (GCRS: obstime=2024-07-13 22:35:40.000, obsgeoloc=(0., 0., 0.) m, obsgeovel=(0., 0., 0.) m / s): (ra, dec) in deg
    (101.281485, -16.71506438)>

This time astropy used our chosen time to convert ICRS to GCRS and you can see that the results are now different.

Adding observer location

You can add location of the observer on the Earth to the SkyCoord object. Like, most of the other arguments, you can do it whether at the time of creation of the object, or adding it after creation using .location attribute. The location of the observer should be an instance of the EarthLocation class. The simplest way to create a location on the earth, is to pass longitude and latitude arguments to EarthLocation. Let's say the location of the observer is in Paris:

>>> from astropy.coordinates import EarthLocation
>>> loc_paris = EarthLocation(lat=48.8575*u.deg, lon=2.3514*u.deg)
>>> print(loc_paris)
(4200841.89608465, 172498.0280838, 4780147.19272296) m

There's a third argument height, which is optional and it defaluts to the surface of the geoid.

One advantage of adding location of the observer to the SkyCoord object, is that you can convert it very easy to Altitude-Azimuth system of coordinates using .altaz attribute. The simple example below, shows how to find the observed coordinates of the star Sirius for an observer in Paris in December 15th 2024 at 23:55:30.

import astropy.units as u
from astropy.time import Time
from astropy.coordinates import SkyCoord, EarthLocation

loc_paris = EarthLocation(lat=48.8575*u.deg, lon=2.3514*u.deg)

t = Time('2024-12-15 23:55:30')

c = SkyCoord(ra=101.287155333 * u.deg,
             dec=-16.716115861 * u.deg,
             frame='icrs',
             location=loc_paris,
             obstime=t)

az = c.altaz.az.deg
alt = c.altaz.alt.deg

print(f'Azimuth  : {az:.2f}')
print(f'Altitude : {alt:.2f}')

Output:

Azimuth  : 164.15
Altitude : 23.02
