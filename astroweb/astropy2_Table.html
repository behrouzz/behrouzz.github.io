Astropy Tables

If you are familiar with pandas, you will learn astropy tables very quickly. Astropy Table is like pandas DataFrame, but with a big difference: it stores not only values, but also units. In other words, it is a data structure that stores quantities. Let's show this with an example.

Suppose that we want to create a table that stores mass and radius of three bodies: Sun, Earth and Moon. We can use pandas as follows:

import pandas as pd

bodies = ['sun', 'earth', 'moon']
mass = [1.989e30, 5.972e24, 7.348e22]
radius = [696340, 6371, 1737]

df = pd.DataFrame({'B': bodies, 'M': mass, 'R': radius})

Let's see the contents of df and its data types:

>>> df
       B             M       R
0    sun  1.989000e+30  696340
1  earth  5.972000e+24    6371
2   moon  7.348000e+22    1737
>>> 
>>> df.dtypes
B     object
M    float64
R      int64
dtype: object

As you see, it is not clear what is the unit of mass and radius in the table. A better approach, is to use astropy Table. This time, we pass the lists as quantities, not just values. Then we create the table using QTable class.

from astropy.table import QTable
import astropy.units as u

bodies = ['sun', 'earth', 'moon']
mass = [1.989e30, 5.972e24, 7.348e22] * u.kg
radius = [696340, 6371, 1737] * u.km

t = QTable(data=[bodies, mass, radius],
           names=['B', 'M', 'R'])

print(t)

Output:

  B       M        R    
          kg       km   
----- --------- --------
  sun 1.989e+30 696340.0
earth 5.972e+24   6371.0
 moon 7.348e+22   1737.0

You can see that this time, each column has its own unit. Similar to pandas, so can access each column as follows:

>>> print(t['M'])
[1.989e+30 5.972e+24 7.348e+22] kg
>>>
>>> print(t['R'])
[696340.   6371.   1737.] km

This time, you get a list of quantities. It is possible to get each element in the list by giving its index:

>>> print('Mass of the Sun is', t['M'][0])
Mass of the Sun is 1.989e+30 kg

For astropy, internally, each column is a Quantity object. So, you can use all of the methods and attributes of the Quantity class for a column, such as .unit and .value attributes. For example, if we want only the values of a column, we should use the .value attribute, which gives us a numpy array.

>>> t['M'].unit
Unit("kg")
>>> t['M'].value
array([1.989e+30, 5.972e+24, 7.348e+22])
>>> type(t['M'].value)
<class 'numpy.ndarray'>

To add a new row to the table, we can use .add_row() method:

>>> ven = ['venus', 4.867e24 * u.kg, 6052 * u.km]
>>> t.add_row(ven)
>>> print(t)
  B       M        R    
          kg       km   
----- --------- --------
  sun 1.989e+30 696340.0
earth 5.972e+24   6371.0
 moon 7.348e+22   1737.0
venus 4.867e+24   6052.0

Another advantage of using astropy Table is that you can create new columns based on calculations on other columns, and the new column will be a Quantity with proper unit and value. As an example, we will calculate the Escape Velocity at the surface of each of the three bodies in our table. The formula is as follows:

\[ V_{e} = \sqrt{ \frac{2 G M}{R} }\]

We will create a new column, Ve in our table:

>>> from astropy.constants import G
>>> t['Ve'] = ( (2*G*t['M']) / t['R'] ) ** 0.5
>>> print(t)
  B       M        R              Ve         
          kg       km    m(3/2) / (km(1/2) s)
----- --------- -------- --------------------
  sun 1.989e+30 696340.0   19526507.818044215
earth 5.972e+24   6371.0    353731.6799453435
 moon 7.348e+22   1737.0    75145.42140469143
venus 4.867e+24   6052.0    327641.6264155266

Well, we expected the unit of Escape Velocity to be m/s, but here we got m(3/2) / (km(1/2) s). We can use a useful method of the Quantity class that decomposes the unit into its irreducible parts. As the name suggests, this methos is .decompose():

>>> t['Ve'] = t['Ve'].decompose()
>>> print(t)
  B       M        R             Ve        
          kg       km          m / s       
----- --------- -------- ------------------
  sun 1.989e+30 696340.0  617482.3945410443
earth 5.972e+24   6371.0 11185.977891849909
 moon 7.348e+22   1737.0 2376.3068737199446
venus 4.867e+24   6052.0 10360.937957550537

Now, the unit of Escape Velocity is in m/s.

For saving the table to the disk, you can use the .write() method. Let's save our table as a FITS file. FITS is a very common and useful file type in astronomy. We will talk about it later.

>>> t.write('bodies.fits')

Use the .read() method of QTable or Table classes as follow to open the saved file:

from astropy.table import Table
t = Table.read('bodies.fits')
