Astropy Python Package

I've never seen an astronomical library more comprehensive than astropy. It is created by great teams and is very well documented. It consists of several modules for dealing with time, coordinates, tables, quantities, models, etc. Some of its functionalities make your everyday life really easy, such as using constants, unit conversions and handling FITS files.

Quantities and Constants

Quantities

Physical quantities have two parts: unit and value. For example, when we say that the speed of light in vacuum is 299792458 m/s, we are talking about a quantity, speed, which has two parts: its unit is metres per second and its value is 299792458. You can create this quantity in astropy as follow:

>>> import astropy.units as u
>>> speed = 299792458 * u.Unit('m/s')
>>> print(speed)
299792458.0 m / s

Note that we passed the unit as a string. We could also use units as follows:

>>> speed = 299792458 * u.m / u.s
You can access the unit and the value of a quantity by using .unit and .value attributes:

>>> print(speed.unit)
m / s
>>> print(speed.value)
299792458.0

One advantage of using quantities, is that you can convert them to other units using .to() method. Let's find the speed of light in km/h:

>>> print(speed.to('km/h'))
1079252848.8 km / h

Constants

Another useful module in astropy is constants. This module provides predefined quantities with units and fixed values. Let me show it with an example. We want to find the Newtonian gravitational force between the Earth and the Sun:

\[ F = G \frac{M_{earth} \times M_{sun}}{r^{2}}\]

We can create each of these quantities as explained above, but the constants module has already defined them, so we can use them directly after importing them from the module. Here, first of all, we import the gravitational constant G, mass of the Earth M_Earth, mass of the Sun M_sun and the Astronomical Unit au which is the average Earth-Sun distance. Then we use these constants in the formula:

>>> from astropy.constants import G, M_earth, M_sun, au
>>> f = G * (M_earth * M_sun) / au**2
>>> print(f)
3.541545424043141e+22 kg m / s2

The resulting unit is kg m / s2 which is newton. Remember \(F=m a\), or if you want to be sure convert it to newton directly with .to() method:

>>> print(f.to('N'))
3.541545424043141e+22 N

You can find other useful constants here.

Besides the contants, astropy lets you use some predefined units. For example, the mass of the earth in a constant whose unit is kg. We want find to the mass of the Earth expressed in solar mass solMass: 
>>> print(M_earth.value, M_earth.unit)
5.972167867791379e+24 kg
>>> print(M_earth.to(u.Msun))
3.003489348850793e-06 solMass

Quantities as Ranges

Astropy lets you create a range of quantities. This is very useful with numpy. Suppose that we want to find the kitenic enery of a mass of 5 kg with different velocities, from zero to 100 km/s. WE can first create our desired range with numpy, then create the range of quantities by multipling the range by our desired unit.

import numpy as np
import astropy.units as u

m = 5 * u.kg
v = np.arange(0, 110, 25) * u.Unit('m/s')
f = 0.5 * m * v**2

print(f)
print(f.to('J'))

Output:

[    0.   1562.5  6250.  14062.5 25000. ] kg m2 / s2
[    0.   1562.5  6250.  14062.5 25000. ] J
